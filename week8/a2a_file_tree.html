A2A POC 完整项目文件树，按层次分组标注每个文件的职责

根目录
a2a-poc/
前端层
├─ frontend/frontend
└─ index.html// 仪表盘 UI · 对话 · A2A流可视化 · 日志面板
启动 + 路由层
├─ main.pyentry// 唯一入口：init DB → launcher → CLI loop
├─ cli.pycli// readline 自然语言交互循环
├─ launcher.pylauncher// asyncio 统一启动三个智能体服务
A2A 协议层
├─ a2a/protocol
├─ protocol.py// Task · Message · AgentCard 数据结构定义
└─ router.py// 进程内消息路由，替代 HTTP，保留协议语义
智能体层
├─ agents/agents
├─ orchestrator.py// LangGraph StateGraph · 意图解析 · 任务路由 · 结果聚合
├─ flight_agent.py// 机票智能体 · AgentCard · search_flights Tool
└─ hotel_agent.py// 酒店智能体 · AgentCard · 时间校验 · search_hotels Tool
工具层
├─ tools/tools
├─ flight_search.py// LangChain Tool：查询 Mock 航班数据
└─ hotel_search.py// LangChain Tool：时间过滤 + 查询 Mock 酒店数据
数据库层
├─ db/database
├─ models.py// SQLAlchemy 表定义：sessions · agent_tasks · results
├─ session.py// PostgreSQL 连接池 · async engine
└─ state_store.py// LangGraph checkpointer 对接 · 状态读写封装
Mock 数据
├─ mock_data/mock
├─ flights.json// 新加坡↔上海 航班时刻 · 价格 · 舱位
└─ hotels.json// 上海酒店 · 区域 · 价格 · 入住时间偏移
配置 + 基础设施
├─ .env// DATABASE_URL · LLM_API_KEY · 环境变量
├─ docker-compose.yml// PostgreSQL 容器定义，一行拉起
├─ requirements.txt// langchain · langgraph · fastapi · sqlalchemy · asyncpg
└─ README.md// 启动说明 · 架构概览
